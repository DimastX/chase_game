# Базовая структура проекта Chase Game

## Обзор проекта

Chase Game - это веб-приложение для игры в догонялки в реальном мире с элементами геймификации. Проект состоит из трех основных компонентов: веб-клиента на React, REST API сервера на Flask и аналитического модуля для обработки географических данных.

## Архитектура проекта

```
chase_game/
├── client/                    # Frontend React приложение
├── server/                    # Backend Flask API
├── chase_game_analysis/       # Модуль анализа и маршрутизации
├── .venv/                     # Python виртуальное окружение
├── requirements.txt           # Python зависимости
└── app.log                    # Лог файлы приложения
```

### Ключевые технологии Frontend

- **React 18.3.1** - основная библиотека UI
- **React Router DOM 6.26.2** - клиентская маршрутизация
- **Axios 1.7.7** - HTTP клиент для API запросов

### Роутинг и навигация

Приложение использует React Router для SPA навигации:
- `/` - главная страница
- `/create-game` - создание новой игры
- `/join-game` - присоединение к существующей игре
- `/game-list` - просмотр списка игр
- `/runner/:gameNumber` - интерфейс убегающего
- `/chaser/:gameNumber` - интерфейс догоняющего

### Модели данных (models.py)

**Game** - модель игры:
- Хранит пароль и имена трех игроков
- Связана один-ко-многим с моделью Player

**Player** - модель игрока:
- Содержит статус (runner/chaser), очки, координаты
- Связана с текущим заданием и историей выполненных заданий
- Поддерживает систему отказов от заданий с таймаутом

**Task** - модель заданий:
- Описание, стоимость в очках, уровень сложности
- Время блокировки при отказе от задания

**Transport** - модель транспорта:
- Типы транспорта и их стоимость за остановку

### API эндпоинты (app.py)

**Управление игрой:**
- `POST /create-game` - создание новой игры
- `POST /join-game` - присоединение к игре
- `GET /games` - список игр
- `POST /catch` - смена ролей игроков

**Игровая механика:**
- `GET /api/runner_data` - данные убегающего игрока
- `POST /api/get_task_by_difficulty` - получение заданий по сложности
- `POST /api/choose_task` - выбор задания
- `POST /api/complete_task` - завершение задания
- `POST /api/refuse_task` - отказ от задания

**Транспорт и геолокация:**
- `POST /api/runner_transport` - списание очков за транспорт
- `GET /api/transports` - список доступного транспорта
- `POST /api/update-location` - обновление координат игрока

**Интеграция с Telegram:**
- `POST /api/verify-telegram-user` - верификация пользователя Telegram

## Модуль анализа (chase_game_analysis/)

### Структура аналитического модуля

```
chase_game_analysis/
├── endpoint_algorithm.py      # Алгоритмы маршрутизации
├── parks.py                   # Работа с данными парков
├── spb_parks.json            # База данных парков СПб
├── spb_parks_self.json       # Кураторская выборка парков
└── Responce.json             # Примеры ответов API
```

### Функциональность модуля

**ParkRouter класс** - интеграция с 2GIS API:
- Построение маршрутов общественным транспортом
- Анализ времени в пути и количества пересадок
- Поиск оптимальных маршрутов до парков

**Работа с географическими данными:**
- Получение данных о парках через Overpass API (OpenStreetMap)
- Фильтрация парков по времени доезда (45-90 минут)
- Расчет центральных координат парков

## Система заданий

### Типы заданий по сложности

**Easy (100-300 очков):**
- Поиск объектов (граффити, магазины, транспорт)
- Простые перемещения и фотографии

**Medium (200-350 очков):**
- Взаимодействие с людьми
- Сложные поисковые задания
- Предсказания и наблюдения

**Hard (250-500 очков):**
- Физические активности
- Длительные ограничения
- Сложные социальные взаимодействия

### Игровые механики

- Система очков с лимитом 1000
- Таймауты при отказе от заданий (3 минуты)
- Отслеживание выполненных заданий
- Автоматическое обновление списка доступных заданий

## Интеграция с внешними сервисами

### Telegram Bot API
- Верификация пользователей через Telegram Mini Apps
- Поддержка двух библиотек: aiogram и pyTelegramBotAPI

### 2GIS API
- Построение маршрутов общественным транспортом
- Получение информации о времени в пути
- Анализ доступности локаций

### OpenStreetMap/Overpass API
- Получение географических данных о парках
- Фильтрация объектов по городу (Санкт-Петербург)
