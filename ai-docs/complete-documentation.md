## Краткое описание проекта

### Что это такое?
Chase Game - это мобильная игра в догонялки, которая превращает городскую среду в игровое поле. Три игрока принимают участие в динамичной погоне: один убегает, выполняя задания и зарабатывая очки, двое других его преследуют.

### Ключевые особенности:
- **Реальный мир как игровое поле** - использование общественного транспорта и городской инфраструктуры
- **Система заданий** - разнообразные квесты разной сложности (100-500 очков)
- **Экономика очков** - баланс между заработком и тратами на транспорт
- **Интеграция с Telegram** - упрощенная авторизация через Mini Apps
- **Геолокация** - отслеживание перемещений в реальном времени

## Технологический стек

### Backend
- **Flask 3.0.3** - веб-фреймворк
- **SQLAlchemy 2.0.35** - ORM база данных
- **SQLite** - база данных для разработки
- **aiogram** - интеграция с Telegram Bot API
- **requests** - HTTP клиент для внешних API

### Frontend  
- **React 18.3.1** - пользовательский интерфейс
- **React Router DOM 6.26.2** - клиентская маршрутизация
- **Axios 1.7.7** - HTTP клиент для API
- **Node.js** - среда выполнения JavaScript

### Внешние интеграции
- **2GIS API** - построение маршрутов общественным транспортом
- **OpenStreetMap/Overpass API** - географические данные о городских объектах
- **Telegram Bot API** - авторизация и уведомления

## Установка и запуск

### Быстрый старт

```bash
# 1. Клонировать проект
git clone <repository-url>
cd chase_game

# 2. Настроить backend
cd server
pip install -r ../requirements.txt
python app.py

# 3. Настроить frontend (в новом терминале)
cd client
npm install  
npm start

# 4. Открыть в браузере
# Frontend: http://localhost:3000
# API: https://localhost:5000 (с SSL)
```

### Системные требования
- **Python 3.8+** для backend
- **Node.js 14+** для frontend
- **Современный браузер** с поддержкой геолокации
- **HTTPS соединение** для production

## Основные компоненты

### Модели данных

**Game** - игровая сессия с тремя игроками
```python
class Game(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    password = db.Column(db.String(80), nullable=False)
    player1_name = db.Column(db.String(80))
    player2_name = db.Column(db.String(80))
    player3_name = db.Column(db.String(80))
    players = db.relationship('Player', backref='game')
```

**Player** - игрок с ролью, очками и местоположением
```python
class Player(db.Model):
    name = db.Column(db.String(80), nullable=False)
    game_id = db.Column(db.Integer, db.ForeignKey('games.id'))
    status = db.Column(db.String(50))  # 'runner' или 'chaser'
    points = db.Column(db.Integer, default=0)
    latitude = db.Column(db.Float)
    longitude = db.Column(db.Float)
    current_task_id = db.Column(db.Integer, db.ForeignKey('tasks.id'))
```

**Task** - игровые задания с разным уровнем сложности
```python
class Task(db.Model):
    description = db.Column(db.String, nullable=False)
    cost = db.Column(db.Integer, nullable=False)
    difficulty = db.Column(db.String, nullable=False)  # easy/medium/hard
```

### Ключевые API эндпоинты

- `POST /create-game` - создание новой игры
- `POST /join-game` - присоединение к игре
- `GET /api/runner_data` - данные убегающего игрока
- `POST /api/get_task_by_difficulty` - получение заданий
- `POST /api/complete_task` - завершение задания
- `POST /api/update-location` - обновление геолокации

## Игровая механика

### Роли игроков
- **1 Runner (убегающий)** - выполняет задания, зарабатывает очки, избегает поимки
- **2 Chasers (преследователи)** - пытаются физически поймать убегающего

### Система очков
- **Максимум:** 1000 очков
- **Заработок:** 100-500 очков за задание (зависит от сложности)
- **Траты:** 30-450 очков за поездку на транспорте

### Типы заданий
- **Простые (100-300 очков):** поиск объектов, фотографирование
- **Средние (200-350 очков):** взаимодействие с людьми, наблюдения
- **Сложные (250-500 очков):** физические активности, долгосрочные ограничения

### Система блокировок
- При отказе от задания игрок блокируется на 3 минуты
- Отслеживание выполненных заданий для предотвращения повторов
